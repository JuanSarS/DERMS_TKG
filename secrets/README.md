# Secretos locales
Copie `opendss.example.json` a `opendss.local.json` y establezca usuario y contraseña SOLO en su equipo. Nunca subir al repositorio. Conexión HTTPS/WSS verificada por defecto. `DERMS_OPENDSS_URL` sobrescribe la base URL si se define.
No se requiere contraseña de Ollama local. No exponga Ollama directamente a Internet.

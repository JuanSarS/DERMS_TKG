# Demostración inicial 10 minutos

1. Mostrar `GET /api/status` con salida REAL y `last_good` de SQLite.
2. Ver CIM100 importado (tripletas y clases) sin inventar la red.
3. Ejecutar laboratorio offline explícito, 48 pasos y despacho con SOC.
4. Abrir SPARQL `as-of` a dos instantes para ver cambio de estado.
5. Ajustar peso `peak`, guardar, y lanzar un nuevo despacho; comparar costo/pico/energía.
6. Si hay OpenDSS Cloud sano y credenciales, ejecutar QSTS remoto, observar WSS, revisar `/results`.
7. Demostrar desconexión (usando pruebas falsas), mostrando permanencia `last_good`.
8. LLM: si Ollama está listo, explicar con run_id/evidencias; si no, explicación determinista.
9. Cerrar con limitaciones: QSTS global no verifica BESS; confiabilidad SAIDI/SAIFI pendiente Tesis II.
